// বাজার দর (BazarDor)

BazarDor is modern web application that helps users check daily market prices of essential products like rice, oil, vegetables, fish, meat etc. in one place.

//Live Website

https://a7-bazar-dor-seven.vercel.app


// Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB Atlas
- Vercel Deployment

// Key Features

1. Market Price Overview

2. Authentication System

3. User Profile Management

4. Product Categories & Sorting

5. Responsive User Interface
